## Objective

建立统一 Workflow Library，将可恢复的临时 workflow、Library draft 和可复用的 immutable published revision 分离，并让 Desktop、CLI、Workflow Tab 与 `@workflow` 共用同一套生命周期和 Durable Workflow Runtime。

## Background

当前 agent authoring drafts/revisions、legacy Workflow Tab 和 mention runtime 已使用不同的数据入口。Draft 虽会持久化，但没有 session ownership 或 Library scope；published revisions 不会出现在现有 Tab；输入框也没有结构化 `@workflow` 调用。

目标生命周期：

| Lifecycle | Recoverable | Workflow Tab | `@workflow` |
|---|---:|---:|---:|
| Temporary | Yes, session-owned | No | No |
| Saved Draft | Yes | Drafts | No |
| Published Revision | Yes, immutable | Published | Yes |

## Scope

### In Scope

- Session/Project/User workflow scopes and a unified Library interface.
- Project workflow packages under `.agverse/workflows/`.
- `/workflow`, `/workflow save`, `/workflow publish`, preview, save and publish tools.
- Unified Library catalog in the Workflow Tab while preserving the legacy canvas.
- Structured single/multiple `@workflow` mentions and durable child workflow execution.
- Additive migration of existing authoring and legacy data.

### Out of Scope

- Full visual editing of the new runtime IR.
- Automatic legacy workflow migration or publication.
- New persistent experience/memory behavior for workflow-local inline agents.

## Risks & Mitigations

| Risk | Impact | Likelihood | Mitigation |
|------|--------|------------|------------|
| Existing legacy and runtime definitions diverge | High | High | Composite catalog with explicit source kind; no silent conversion |
| Project files reference missing tools or agents | High | Medium | Versioned schema, dependency diagnostics, frozen published revisions |
| Multiple mentioned workflows duplicate child runs after recovery | High | Medium | Persist parent/child correlation and derive idempotent child request IDs |
| Saved workflow raises caller authority | High | Low | Intersect frozen permissions with caller ceiling at every invocation |

## Success Criteria

- Temporary workflows survive session resume, remain hidden from Library, and are deleted with the session.
- Drafts appear in the correct Project/Personal scope but cannot be mentioned.
- Published revisions are immutable, discoverable, pinned at send time and executable via `@workflow`.
- Multiple workflow mentions preserve declared dependencies and recover without duplicate children.
- Legacy workflows remain editable and ordinary prompts/agent mentions are behaviorally unchanged.
