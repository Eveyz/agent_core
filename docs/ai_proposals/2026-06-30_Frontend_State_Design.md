# 2026-06-30 Frontend State Design for Agents and Workflows

根据需求，为了支撑企业级的 Master-Detail Agents 页面以及高可观测性的 Workflows 编排工作台，我们需要对当前的 Redux State 进行扩展和重构。

## 1. State 接口设计 (Data Flow Structure)

### 1.1 `workflowSlice.ts` 的扩展设计

核心是为了支持运行时可观测性，特别是针对节点状态的流转（如取消、跳过、失败）以及与后端的实时事件同步。

```typescript
// src/features/workflow/types.ts

// 扩展节点运行状态枚举
export type NodeRunStatus = 
  | 'pending'    // 默认待执行
  | 'running'    // 正在执行 (显示呼吸灯/进度条)
  | 'completed'  // 执行成功
  | 'failed'     // 执行失败 (显示 Error Badge)
  | 'cancelling' // 用户点击 Stop 后，等待后端强杀确认时的中间态
  | 'cancelled'  // 成功被强杀
  | 'skipped';   // 上游节点失败或被取消后，下游连带跳过的状态

// 扩展 Workflow 整体运行状态
export type WorkflowRunStatus =
  | 'idle'
  | 'running'
  | 'cancelling'
  | 'completed'
  | 'failed'
  | 'cancelled';

export interface WorkflowRunNodeResult {
  id: string;
  workflow_run_id: string;
  node_id: string;
  agent_history_id: string;
  status: NodeRunStatus; // 从 string 强化为具体枚举
  input: unknown;
  output: unknown;
  error: string;
  token_input: number;
  token_output: number;
  cost_usd: number;
  latency_ms: number;
  started_at: string | null;
  finished_at: string | null;
  created_at: string;
  
  // UI 专用扩展：用于在抽屉中展示实时的思考流与工具调用
  // 后端通过 Tauri Event 流式推给前端，前端在这里做追加
  live_logs?: LiveLogEntry[]; 
}

export interface LiveLogEntry {
  id: string;
  type: 'thought' | 'tool_call' | 'observation' | 'error' | 'warning';
  content: string;
  timestamp: string;
}

export interface WorkflowRunResult {
  run_id: string;
  status: WorkflowRunStatus; // 从 string 强化
  output: unknown;
  error: string;
  total_token_input: number;
  total_token_output: number;
}
```

### 1.2 `agentSlice.ts` 的扩展设计

Agents 页面的状态基本满足需求，但为了更好地支撑 Master-Detail 布局的四个 Tabs，我们需要在 UI State 上做一点补充。

```typescript
// src/features/agents/agentSlice.ts

interface AgentState {
  agents: AgentDef[];
  loading: boolean;
  error: string | null;
  
  // 左侧 Sidebar 选中的 Agent
  selectedAgentId: string | null;
  
  // --- 右侧 Tabs 数据流 ---
  history: AgentHistoryEntry[]; // 用于 History Tab
  memories: AgentMemoryRecord[]; // 用于 Memory Tab
  
  // Agent 的专属技能集合 (由后端的 skills 字段延伸，需确保前端有对应的解析逻辑)
  // 用于 Skills Tab
  skillsLoading: boolean; 
  
  running: boolean;
  runOutput: string | null;
}
```
