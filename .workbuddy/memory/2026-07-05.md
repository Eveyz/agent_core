## Batch reads prompt 优化

- 在 `core/src/prompt.rs` 的 `DEFAULT_PRINCIPLES` 中「File operations」段落新增一条 batch reads 引导规则
- 核心语义：当需要读取多个独立文件时，**一轮内发出所有 read_file 调用**，不要分多轮单次读取
- 理由：系统已支持并行执行独立 tool calls，N 个读放一轮 = 1 次 LLM 调用，分 N 轮 = N 次
