## Revert include! pattern → idiomatic Rust module refactoring (run)

之前的 Phase 4.1 使用 `include!()` + `.inc.rs` 文件拆分 `run.rs`，这不符 idiomatic Rust 最佳实践。现在改为标准 Rust 模块系统重构：

### Before（反模式）
```
runtime/
  run.rs          (440 lines core)
  run_lifecycle.inc.rs
  run_turn.inc.rs
  run_compact.inc.rs
  run_compact2.inc.rs
  run_recovery.inc.rs
  run_context.inc.rs
  run_helpers.inc.rs
```
使用 `include!("run_lifecycle.inc.rs")` 等 7 个宏将代码拼入 `impl Run` 块。

### After（idiomatic Rust）
```
runtime/
  run/
    mod.rs        (struct, impl core, Drop, free functions)
    lifecycle.rs  (run, run_loop, poll_commands, wait_for_resume, resolve_approval)
    turn.rs       (run_turn, model_turn, collect_stream)
    compact.rs    (maybe_compact, force_compact)
    recovery.rs   (try_recover)
    context.rs    (build_messages, snapshot_messages_for_hook, decompose_goal, refresh_context_segments)
    helpers.rs    (write_session_memory, cancel_and_cleanup, cleanup_on_exit)
```
每个 submodule 都是独立文件，有自己的 `use` 导入和 `impl Run` 块。child module 可通过 `super::` 访问 parent module 的私有类型（TurnOutcome, RecoveryOutcome, RunError, 常量和 helper 函数）。

编译通过（cargo build 成功），零 breaking change。
