# 2026-07-08

## 架构讲解：ContextEngine + 压缩流水线
- 向用户解释了 7 段式 context 设计：核心是 KV/prompt cache 命中率，按变化频率分组（Stable→frozen system；Semi/Dynamic→独立注入消息）。
- 解释了 5 阶段压缩流水线（snip→dedup→chunk→LLM summary→gradient）的"由廉价到昂贵、早停"升级阶梯，目标是尽量不调 LLM、不破坏 DeepSeek 前缀缓存。

## 发现的代码问题
- `compressor.rs` 里 Stage 5 "gradientCompact" **没有实际的 `gradient_compact()` 函数**。"梯度化"实际由 `runtime/run/compact.rs::maybe_compact`（chunked_drop 优先 → trim_to_fit → LLM summary 兜底）+ `context.rs::micro_compact` / `chunked_drop` 共同实现。
- `Compressor` 的 `gradient_keep_recent` / `gradient_snip_range` 两个字段已声明但**未被任何代码读取**（死配置）。
- 7 段式那边也有不一致：`init_segments` 把 environment 推进了 `stable_segment_names`，但 `assemble_system_prompt` 只收 `Stability::Stable`（environment 是 SemiStable+PerTurn），导致 `verify_prefix_stability` 误报前缀漂移。

## 概念链路（用户追问：两个原则如何驱动前面两个设计）
- "深度利用 KV Cache Hints 消除 token 浪费" = 7 段式的**机制落地**：7 段把稳定前缀隔离（结构），cache_hint()/stable_prefix_fingerprint()/verify_prefix_stability()/stable_prefix_text() 是"证明没变 + 告诉推理引擎复用"的机制。没有 hint，切了也白切。
- "缓解注意力衰减" = 5 阶段压缩（尤其 gradient 年龄分级）的**动机**：窗口越短越密，模型注意力越聚焦。压缩把历史封顶、信噪比拉高。
- 二者正交互补：成本/算力轴 × 质量/效果轴。注：stable_prefix_text()（含 env, SemiStable）与 assemble_system_prompt()（不含 env）对 environment 的归属不一致，本地模型 KV 预热时前缀可能不匹配 → cache miss，是端到端真正生效前的 loose end。

## 用户追问：CacheHint 到底怎么告诉本地模型（Ollama / transformers）
- 关键事实：`CacheHint`（`core/src/context.rs:39`）的 doc comment 写的是"for local models (llama.cpp, Ollama)"，但全代码库**没有任何推理路径消费它**。`OpenAIClient`（`core/src/client/mod.rs`）是纯 OpenAI 兼容 HTTP 客户端，`build_request_body` 只发 model/messages/tools，**没有 cache_control / cache_prompt 字段**。所以 CacheHint 目前只是诊断量（/context 调试 + 遥测事件），无论本地还是远程都没真正传给模型。
- 项目当前 config.toml 跑的是远程 DeepSeek（`base_url=https://api.deepseek.com/v1`），Ollama 那行 `http://localhost:11434/v1` 是注释掉的。所有后端都走同一条 OpenAI 兼容路径。
- 本地引擎的"提示"真相：几乎都不靠 per-request 参数。Ollama=自动前缀缓存（无 param，只要前缀逐字节相同即可，7 段式 frozen system prompt 已满足）；llama.cpp server=`/completion` 原生端点支持 `cache_prompt:true`；vLLM/TGI（transformers 服务器）= server flag（vLLM `--enable-prefix-caching`）自动复用。唯一在 request body 里显式传 hint 的是 Anthropic 的 `cache_control:{type:ephemeral}`，但本仓库客户端不支持该格式。
- 结论：让 hints "名副其实" 需要（1）把 server 端前缀缓存打开（Ollama 默认开，llama.cpp 开 cache_prompt，vLLM 开 flag）；（2）把 `cache_hint()` 真正接进 `build_request_body`（Anthropic 系加 cache_control；本地系靠 server flag + 稳定前缀纪律即可，无需 per-request 字段）。
