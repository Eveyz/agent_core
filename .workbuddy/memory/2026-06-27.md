# 2026-06-27

## sidebar-collapsed 展开按钮重构

- **问题**: 侧边栏折叠后的展开按钮（`sidebar-expand-btn`）使用 `position: absolute` 定位在 `left: 8px`，与 `main-header` 中的 session title 重叠。
- **修改**:
  1. `app/src/App.tsx`: 将展开按钮从 `main-area` 的独立 absolute 定位元素，移到 `header-title` flex 容器内（条件渲染在 session title 之前）。图标从 `ChevronDownIcon`（旋转 90°）换成 `PanelRightIcon`，新增 `PanelRightIcon` 导入。
  2. `app/src/styles/layout.css`: 移除 `.sidebar-expand-btn` 的 `position: absolute`、`top`、`left`、`z-index` 属性，新增 `flex-shrink: 0`，按钮现在通过 flex 布局自然排列，不再重叠。
- **验证**: TypeScript 编译通过，PanelRightIcon 模块存在且可导入。

## 窗口控制按钮保留（收起侧边栏时可用）

- **问题**: 侧边栏收起后 `sidebar-column` 宽度为 0，`CustomTitleBar` 内的关闭/最小化/最大化按钮完全不可见。
- **方案**:
  1. 新建 `app/src/components/layout/WindowControls.tsx`：从 `CustomTitleBar` 抽离窗口控制三按钮为独立组件，自带最大化状态管理。
  2. `app/src/components/layout/CustomTitleBar.tsx`：用 `<WindowControls />` 替代内联按钮。
  3. `app/src/App.tsx`：侧边栏收起时，在 `header-title` 中先渲染 `<WindowControls />` 再渲染 `sidebar-expand-btn`（`PanelRightIcon`），窗口控制按钮始终可访问。
- **验证**: TypeScript 编译通过。
