### Subagent 缺少 Working Directory 信息（两轮修复）
- **问题第一层（informational）**: 主 agent 的 context 通过 `build_environment_string` 注入了 `Working Directory`，但 subagent 的 context 是 `Subagent::new()` 裸创建的（只有 system prompt），完全没有 CWD 信息。进程 CWD 在 `app/` 目录下，subagent 不知道项目根在哪，找不到 `core/src/context.rs`。
- **修复 v1**: system prompt 注入 `Working Directory: {cwd}`，但用的是进程 CWD（`app/`），模型看到了路径但工具级仍然无法解析相对路径。
- **问题第二层（tool-level）**: `glob`/`grep` 默认 base path 是 `.`（进程 CWD 即 `app/`），`read_file` 的相对路径也基于进程 CWD 解析。所以 `glob("**/*.rs")` 只扫描 `app/` 返回 3 个文件，看不到 `core/`/`cli/` 等 sister crates。
- **修复 v2**: 
  - 新增 `find_workspace_root()` — 从 CWD 向上找 `Cargo.toml` 定位 workspace 根
  - 新增 `CwdGuard` — RAII scope guard，subagent 运行前 `set_current_dir(workspace_root)`，运行完后恢复原 CWD（panic 安全）
  - system prompt 注入的是 workspace root 路径
